# ともじゃん（β版）

推し活SNS「ともはね」とつながるゲームのアプリ「ともじゃん」です。はじめは、だれでも分かる**じゃんけん**だけ。ほかのゲームは、**みんなの声（意見）をまとめてから**作ります。

## 起動

Node.js 20 以上が必要です。外部パッケージは使っていません。

```sh
npm start        # http://localhost:3300
npm test
```

| 環境変数 | 中身 |
| --- | --- |
| `TOMOHANE_URL` | ともはねのアドレス（ふだんは `http://localhost:3000`） |
| `LINK_SECRET` | ともはね と同じ値にする合言葉（サーバーどうしの確認用）。**本番では必ず設定する**（未設定だと開発用の値） |
| `PORT` | ポート（ふだんは 3300） |

## 遊び方

1. ともはねの町の地図で、シバの家の上の「✊✌️✋ じゃんけん」を押す（シバが家にいるときだけ光る）
2. 「ともはねでログイン」→ ゲームが開く
3. 「対戦をさがす」→ グー・チョキ・パーで3本勝負（2本先取）
4. 勝ち数は ともはね にとどいて、アカウントの画面に出る（あとで、きせかえの飾りなどのごほうびにつなげる）

## キャラの仕分け（組み合わせ）

- **年齢の区分は必ず同じ**：子どもは子ども、中高生は中高生、大人は大人とだけ組む。どんなに待っても混ぜない
- **うでまえが近い人を先に**：まだまだ（10回まで）／のびしろ／ふつう／つよい。15秒待ったら、うでまえが少しちがっても組む
- **はじめての3回**と、**30秒だれも見つからないとき**は、🐕 シバが相手
- 組み合わせの理由を、🐱 ヤマネコが画面に出す
- 1日21回まで（大人も子どもも。球技の21点にちなむ）

## 安心のしくみ

- チャットは決まった言葉だけ（よろしく！／ナイス！／ありがとう／またね！）
- ともはね から受けとるのは、ゲーム用の番号（ともはねの ID そのものではない）・表示名・年齢の区分だけ
- ともはね に返すのは、勝ち数と参加回数だけ
- 通行証は1分だけ・1回だけ使える。ゲームにパスワードは置かない
- データはメモリの中だけ（β版。再起動で最初にもどる）

## みんなの声

「次はどんなゲームがいい？」に意見を書き、いいねできます。🐱 ヤマネコが、多い種類（クイズ・しりとり・音楽・パズル・謎解きなど）をまとめます。1人1日5つまで。電話番号やメールアドレスは書けません。
